# 使用说明

## 快速开始

1. 右键 `multi_wechat.bat`，选择"以管理员身份运行"（推荐，避免权限问题）
2. 在弹出的命令行窗口中输入要打开的微信数量
3. 等待脚本依次启动微信实例

## 自定义配置

打开 `multi_wechat.bat`，修改顶部变量：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `WECHAT_PATH` | 微信可执行文件绝对路径 | `D:\Tencent\Weixin\Weixin.exe` |

启动间隔调整：修改 `ping -n 1 -w 500 127.0.0.1` 中的 `-w 500`（毫秒），值越大间隔越长。

## 常见问题

### 微信安装路径找不到？

- 右键桌面微信快捷方式 → 属性 → 复制"目标"中的 `.exe` 路径
- 把该路径填入 `WECHAT_PATH`

### 启动后只有第一个微信能登录？

请确认您使用的是支持多实例的微信版本（一般 3.9 及以上已支持），或在登录第一个微信后等待其完全加载再启动后续实例（可适当增大 `-w` 值）。

### 提示"不是内部或外部命令"？

请使用 Windows 自带的 CMD 运行 BAT，不要在 PowerShell 中直接运行。
